More
Previous version
Switches back to the version that ran before the last update. Without an earlier downloaded version it uses the built-in one, which stays until you press Update.
Built-in version
Switches to the version that came with the import. It stays until you press Update.
Reinstall
Downloads the program again and replaces the stored copy. Your settings stay.

  1. Click Copy import code.
  2. In Streamer.bot, delete the old Printer Bot action.
  3. Open Import (top bar), paste, and click Import.
  4. Reload this dock.
Renderer updates
Where Printer Bot looks for newer receipt layouts. Normally this dock.
Newer receipt layouts and program updates are only used if the author signed them. Off downloads nothing and uses the built-in layout, and a program update you installed earlier keeps running until you press Use the built-in version.
Renderer
Reset throws away any downloaded copy and goes back to the layout built into the action.

Keeps the address, port and password in this browser so OBS reconnects after a restart. Untick it on a shared computer: the password is then not saved.

This dock is loaded over plain http. Anyone on the way can change this page, and a Streamer.bot password cannot be used from it. Use an https address for the dock if you can.

This dock is on https but Streamer.bot is reached over plain ws://. Browsers may block that unless Streamer.bot is on this computer.

This dock is loaded from a web server but talks only to Streamer.bot on this computer. If your browser asks whether this site may connect to devices on your computer or local network (it may be called "Apps on device"), choose Allow.

In Streamer.bot, enable Servers/Clients → WebSocket Server and keep the port here in sync.
